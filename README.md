# 📅 Project Timeline

团队共用的项目时间线 / Shared team project timeline. 任务 = GitHub Issue → 自动画成甘特图 / Each task is a GitHub Issue, shown as a Gantt chart.

- 看进度 View: https://moonsiao.github.io/project-timeline/
- 新增任务 New task: 网页「＋ 新任务」/ click "＋ New Task"
- 更新进度 Update: 点任务 → 在 GitHub 编辑 Issue / click a task → edit the Issue on GitHub
- 完成 Done: Close issue
- 负责人 Owner: Issue → Assignees
- 语言 Language: 右上角 中文 / EN 切换
